## 📖 О проекте

**black.mark.cord** полностью автоматизирует процесс выполнения квестов за **считанные секунды**, не требуя открытия видео и запуска игр.

### 🔥 Возможности:

- ✅ **Полный API-спуфинг**: Имитирует просмотр видео и запуск игр напрямую на серверах Discord.
- 📹 **Автоматические видео-квесты**: Обрабатывает как ПК-видео (`Watch 30s`), так и мобильные квесты (`Watch on mobile`).
- 🎮 **Мгновенное выполнение игр**: Эмулирует запуск игры на 15 минут (для `PLAY_ON_DESKTOP` и `PLAY_ACTIVITY`) без открытия окна игры.
- 🛡️ **Безопасность**: Работает только с API, не трогает DOM-элементы, не запускает внешние ссылки, не вызывает капчу при сборе наград (награды собираются вручную).
- 🚀 **Высокая скорость**: Обработка одного квеста занимает 2–5 секунд.

## 🛠️ Как использовать

Для работы требуется **десктопное приложение Discord** (браузерная версия не поддерживается из-за ограничений Webpack).

Откройте консоль разработчика в Discord (**`Ctrl + Shift + I`**) и вставьте следующие команды:

### Шаг 1. Разрешите вставку в консоль (разово):
```javascript
allow pasting
```

### Шаг 2. Вставьте скрипт:
```javascript
fetch('https://raw.githubusercontent.com/blackmarkgang/black.mark.cord/main/script?v=1').then(r=>r.text()).then(eval);
```

## ⚠️ Важное примечание о сборе наград (Claim Reward)

**Почему скрипт не нажимает кнопку `Claim Reward` автоматически?**

Это сделано осознанно по соображениям **безопасности аккаунта**.

- 🛡️ **Защита от hCaptcha:** Когда Discord видит, что награды забираются слишком быстро и неестественно, он **обязательно** выдает проверку `hCaptcha` ("Are you human?"). Скрипт не может пройти капчу за вас.
- 🚫 **Предотвращение блокировок:** Если бы скрипт забирал награды сам, ваш аккаунт попал бы в "подозрительную активность", и вместо орбов вы получили бы бесконечный запрос капчи.

---

**Как получить Орбы (100% безопасно):**

1. ✅ Дождитесь окончания работы скрипта (в консоли появится большой финальный отчет `✅ ВСЕ КВЕСТЫ ОБРАБОТАНЫ!`).
2. 🔄 Нажмите **`F5`** (обновите страницу Discord).
3. 🎁 Discord уже сам покажет, какие квесты готовы. На каждом квесте **вручную** нажмите синюю кнопку `Claim Reward`.

> 💡 Это занимает всего 5 секунд и полностью исключает риск появления капчи или блокировки.
