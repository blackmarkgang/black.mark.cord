## 📖 О проекте

**black.mark.cord** — это мощный JavaScript-скрипт, работающий через инжект в Webpack Discord (Desktop App). 

Он полностью автоматизирует процесс выполнения квестов за **считанные секунды**, не требуя открытия видео, запуска игр или танцев с бубном.

### 🔥 Возможности:

- ✅ **Полный API-спуфинг**: Имитирует просмотр видео и запуск игр напрямую на серверах Discord.
- 📹 **Автоматические видео-квесты**: Обрабатывает как ПК-видео (`Watch 30s`), так и мобильные квесты (`Watch on mobile`).
- 🎮 **Мгновенное выполнение игр**: Эмулирует запуск игры на 15 минут (для `PLAY_ON_DESKTOP` и `PLAY_ACTIVITY`) без открытия окна игры.
- 🛡️ **Безопасность**: Работает только с API, не трогает DOM-элементы, не запускает внешние ссылки, не вызывает капчу при сборе наград (награды собираются вручную).
- 🚀 **Высокая скорость**: Обработка одного квеста занимает 2–5 секунд.
